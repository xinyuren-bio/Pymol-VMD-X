# Pymol-VMD-X 使用手册

[项目首页](../README.md) · [构建依赖](../INSTALL) · [变更日志](../CHANGELOG.md)

## 更新 macOS 本机安装

在已有桌面应用和对应虚拟环境的情况下，从仓库根目录运行：

```bash
.venv/bin/python tools/update_macos.py
```

命令核对应用启动器所用的虚拟环境，同步 Python 和 Qt 界面文件，并用安装版测试顶部风格按钮和原位表示。
验证失败会回退本次更新。更新后完全退出并重新打开应用，在 **关于 Pymol-VMD-X** 查看
Git 提交号和北京时间的更新时刻。「含工作区改动」表示本机构建还包含未提交的改动。
改动 C/C++ 内核、资源或依赖时，按原构建流程重新安装。

## 智能科研出图

加载结构后，点击顶部 **智能风格** 中的 **期刊简约 / 卡通插画 / 通透表面**，
自动识别蛋白及候选配体并预览。多个候选支持勾选、全选与清空。
通过 **插件 → 科研出图 → 预览与导出…** 调整配体、构图和配色。蛋白默认按链着色，
在链列表中选一条链，点 **选色…** 即可单独调整，也可以切换为单色。勾选的配体
单独显示，默认按元素着色，与蛋白链色同时生效。需要指定配体的碳原子颜色时，选择
**碳色可调**；其他元素仍保留各自的元素色。切换风格时会保留配体勾选、着色方式与
手动设置的颜色，其余颜色会采用新风格的默认值。

**期刊简约**使用纯白背景、低饱和度链色、细卡通和棒状配体。**卡通插画**使用暖底、
鲜明链色、更粗的卡通和球棍配体，光线追踪导出时有深色描边与更强的明暗层次。
构图可选“结构总览”或“结合口袋”。
手动调整视角后，勾选“保持当前视角”再导出。默认 PNG 为 1800 × 1400、300 DPI，
支持透明背景。**光追预览…** 按导出宽高比生成小图，可检查描边、光照与透明背景。
**撤销上次样式**恢复上一次出图前的显示、光照和视角，保留后来载入的对象和坐标编辑。
**恢复原始**仍可恢复首次预览或出图前的完整会话。

调好风格和视角后，点 **保存图稿方案…**，另存一份 JSON。它保存布局、相机、链色、
配体勾选及 PNG 参数。勾选 **使用当前背景与光照** 时，也记录当前光照和背景，否则
使用所选风格的默认外观。重新打开结构或 PSE 后点 **打开图稿方案…**，选择恢复原视角，
或按新结构重新构图。界面会列出无法明确匹配的链和配体，确认后只应用能匹配的项目。
JSON 与坐标文件可分别保存。

候选检测限定于启用的分子对象，排除水、离子及常见添加剂，并要求至少 5 个重原子；
肽类配体、共价配体和特殊辅因子可能需要手动处理。结合口袋显示配体 4.5 Å 内的蛋白残基，
不自动推断或标注氢键。自动构图后仍建议检查遮挡与科学表达。

开发验证：使用本地 PyMOL Python 环境，以 unittest 加载
`testing/tests/api/test_publication.py`；测试无需联网或额外 pytest 依赖。

顶部 **出图工具栏** 提供白/灰/黑背景、四种光照、阴影/轮廓/雾化开关，
以及卡通/棒状/球体/表面显示；可通过 **显示 → 出图工具栏** 隐藏或恢复。
阴影与轮廓在光线追踪渲染/导出时生效。使用工具栏调整外观后，科研出图对话框
默认勾选 **使用当前背景与光照**，也可取消以使用默认出版样式。

## 结构对照

在 **插件 → 结构对照…** 选参考与比较结构。可选同一个对象的不同坐标状态，分别用
PyMOL 或 VMD 选择表达式限定参与对齐和显示的范围。**对齐并叠合**会创建两个显示副本，
按匹配的 Cα 做刚体拟合，显示匹配数量和 RMSD。**同尺度并排图…** 使用相同的视角、
中心和比例渲染两张图，可导出为一张 PNG。**清除对照**会删除显示副本，并恢复源对象的可见性。

## 轨迹分析

从播放器或 **插件 → 轨迹分析…** 打开，选择带多个坐标状态的对象，设置起止帧和步长。
窗口里的 **选择语法** 控制两个输入框。选 **VMD** 后可输入 `resname ALA GLY`、
`resid < 10 and resid > 5` 或 `resid 6 to 9 and name CA`。VMD 的 `index` 从 0
起算，PyMOL 的 `index` 从 1 起算。VMD 中依赖坐标的条件（如 `within`）在距离分析
的起始帧或 RMSD 的参考帧求值，随后用同一批原子计算所有采样帧。
**两原子距离**要求 A、B 各匹配一个不同的原子，例如 VMD 的 `resid 6 and name CA`
和 `resid 9 and name CA`。
**对齐后 RMSD**用 A 中的原子对齐到指定参考帧，并计算这些原子的拟合后 RMSD。
点击曲线跳到最近的采样帧。CSV 写出一基帧号、Å 单位的测量值，以及对象、选区语法、选区和参考帧。
距离与 RMSD 直接使用载入的坐标。若原始轨迹有分子跨盒问题，先做下文的周期边界处理。

## 粗粒化连续显示

加载 Martini 风格 PDB 后，点击顶部 **粗粒化**，选择源对象与 **连续形态 / 球棍连接**，
再点 **应用显示**。按珠名识别蛋白主链、核酸、脂质与固醇，生成独立显示副本；
源文件、源坐标、原子名称和原有连接保持不变，**恢复源对象**可恢复原来显示。

默认启用 **自动匹配已保存拓扑**，按残基名、完整珠名集合与分子边界匹配本地连接模板。
已保存 Paloncýová 等人 2023 年 RNA–LNP 体系的原始拓扑，包含 ALC-0159（AL15）、
带电源模板 ALC-0315（AL31）、辅助磷脂（源名称 DPPC）、胆固醇与 poly-U RNA 10-mer。
该文献采用作者修改的 Martini 3.0.0，保留其 SN3r–水相互作用修改；原始文件与 SHA256
校验值位于 [模板目录](../data/cg_templates/paloncyova_2023_martini3/)。源数据来自
Paloncýová 等人的 [Zenodo 7456781](https://zenodo.org/records/7456781)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）。
源 ITP 和 TOP 文件按原样归档，`templates.json` 从中提取珠名、键、约束与虚拟点规则供显示使用。
[原论文](https://doi.org/10.1021/acs.jpcb.2c07671)

模板里的力场珠子类型、电荷、键、约束和虚拟点定义均保留。PDB 通常没有力场类型与电荷，
因此名称匹配只用于选择连接模板，不能据此证明任意导入结构的力场版本或质子化状态。
只将模板中的键/约束用于连接，虚拟点单独显示，不将虚拟点构造关系伪装成化学键。
不完整或未知组分使用明确标记的几何近似；取消自动匹配可全部使用几何显示。
RNA 模板限定完整的 U10 链，不推广到任意核酸序列或蛋白。

也支持按整个对象当前原子顺序编号的零基键对文件，以及原子名称和顺序匹配的单分子展开
`.itp/.top`，外部文件优先。含 `#include`、条件编译或多种分子类型的用户完整
GROMACS 拓扑不直接解析；内置模板由 `tools/build_cg_templates.py` 从归档源文件预先整理，
不需要 GROMACS 或网络即可使用。几何近似仅用于连续显示，不是力场拓扑，也不会生成全原子坐标；
蛋白主链没有二级结构信息时不推断螺旋。连接显示与全原子回映射的区别可参考
[MartiniGlass 官方说明](https://martiniglass.readthedocs.io/en/stable/advanced_options.html)。

样本回归测试可通过环境变量 `PYMOLX_CG_SAMPLE` 指定只读 PDB；常规测试不依赖个人文件路径。

## 周期性边界与轨迹显示

在播放器中，点击 **轨迹分析…** 右侧的 **显示盒子**，可显示当前可见分子自带的
周期盒。切换轨迹帧时，盒线随该帧的尺寸和角度更新。再次点击 **关闭盒子** 即可隐藏。

XTC 保存每帧坐标和盒子。若轨迹在盒边把分子切开，先用与原子数和顺序匹配的生产模拟拓扑
（优先使用 GROMACS 的 `.tpr`）逐帧拼完整分子，再对需要观察的聚集体重建周期镜像并居中。
通用力场参数文件无法确定轨迹中的分子边界。处理后先打开匹配的结构文件，再把处理后的 XTC
载入同一对象，从第一帧播放。

## 生成 GROMACS 模拟包

从 **插件 → 生成 GROMACS 模拟包…** 选择单链或多链蛋白对象，也可按住 macOS 的
⌘ 键或 Windows／Linux 的 Ctrl 键多选对象。各对象使用所选坐标状态，只有一个状态的
对象使用其唯一状态。打包保留场景中的链间相对坐标。遇到重名链时为重复项分配新标签，
在 `chain-map.json` 中保留对象名、原始链标识和状态。工具环境需要 AmberTools、
ParmEd 和 GROMACS，本机会优先识别可用的 WebMD Conda 环境。
选择温度和生产时长后导出 ZIP。流程沿用 WebMD 的 AMBER ff14SB／TIP3P 组合，
默认盒边距 12 Å，加入 Na⁺／Cl⁻ 中和，背景盐浓度为 0 M。常规链端按带电状态处理，
输入 `HIS` 使用 `HIE`，显式 `HID`、`HIE`、`HIP` 会保留。每条链需要连续主链和
单字符 PDB 链标识。已有交联（含二硫键）、配体和其他未知组分需要另行准备拓扑。

发现链间连接时，打包窗口会逐对列出链、残基、原子、距离和记录来源。当前对象键表可能
包含 PyMOL 载入时按距离推断的键，请与原始文件和界面几何一起核查。对使用原始 PDB 的
命令行预检，报告也会标明文件中的链间 `LINK` 或 `SSBOND`。确认是非共价复合物时，
应在副本里修复异常近接触并去掉已确认的误键，再重新加载核对。

### 四阶段 MDP

点击 **编辑四阶段 MDP…**，分别查看和修改能量最小化、NVT、NPT 和生产模拟的完整文本。
可导入、导出或恢复当前阶段默认值。温度与生产时长表单只影响使用默认值的阶段。
打包保留自定义文本，并用已准备的体系对四个阶段分别运行 `gmx grompp`，错误会标出
对应阶段以及 GROMACS 的选项或文件诊断。运行脚本随后使用真实的前一阶段输出重新生成
每一阶段的 TPR。高级参数所引用的索引组必须存在于包的 `index.ndx`。

### 导入 CHARMM-GUI 的 CHARMM36m 作业

在 [Solution Builder](https://charmm-gui.org/?doc=input/solution) 选用 CHARMM36m，
需要时在 **Lys / Arg PTMs** 中设置乳酸化，再选择 **GROMACS** 输出。对于已有的
`XRW`，可用 PTM 窗口生成该位点的 `LYS` 副本，让 Solution Builder 重新添加乳酸化。
导出后用生成的结构核对目标位点和乳酸基的构型。

下载完整作业后，在 **插件 → 生成 GROMACS 模拟包… → 导入 CHARMM-GUI 作业…**
选择 `.tgz`、`.tar.gz` 或 `.tar`。插件从作业的 `gromacs/` 目录读取
`step3_input.gro`、`topol.top`、`index.ndx`、拓扑依赖和阶段 MDP，保留其力场、
坐标、原始 MDP 和阶段顺序，并逐阶段运行 `grompp`。AMBER 表单里的时长和温度只作用于
AMBER 打包。导入在本地完成，生成的 ZIP 可通过 `bash run_md.sh` 启动。

### PTM 参数库

- `SEP`、`TPO`、`PTR` 对应当前 PTM 工具生成的双负磷酸化残基。支持导入用 `S1P`、
  `T1P`、`Y1P` 明确标记的单负状态。首次使用时从 AmberTools 归档
  `phosaa14SB.lib`、对应的参数补充文件及加载脚本，以后核对参数文件与基础力场的
  SHA‑256 后复用。
  [phosaa14SB 参数来源](https://doi.org/10.1021/acs.jctc.4c00732)
- `XRW` 和 `D8R` 分别表示 L‑乳酸化（2S）和 D‑乳酸化（2R）。可登记各自已核验的
  ff14SB 蛋白内残基模板。Huang 等人的补充文件是封端的独立分子，从坐标读出的乳酸基
  构型为 2R，缺少可直接迁移到任意多肽的连接参数，因而作为参考来源归档。
  [乳酸化补充数据来源](https://doi.org/10.1038/s41589-025-02107-8)

默认参数目录为 `~/.pymolx/md-parameters/ff14SB`。点击 **管理 PTM 参数…** 可查看归档状态、
从工具环境预存磷酸化参数，或选择一个乳酸化类型并导入含 `residue.lib`、`residue.frcmod`
和 `template.json` 的目录。程序检查三个文件后，将其登记到对应的 `XRW` 或 `D8R`
子目录。之后每次打包都按残基名读取已有模板。
JSON 记录 `force_field`（`ff14SB`）、`residue`、`configuration`（`2S` 或 `2R`）、
`charge`（0）、`source`、两份文件的 `sha256`，以及已核验的基础力场
`base_sha256`（可从同一运行环境生成的普通蛋白模拟包的 `manifest.json` 查看）。
如原子名不同，使用 `atom_names` 从 CCD 原子名映射到模板原子名。OFF 库须包含一个指定
残基以及 C、N 两个肽链连接位点。打包时再次核对重原子、净电荷、前后肽键和乳酸基构型。

参数未就绪时，界面会列出缺少的文件和目标目录。**导出位点短肽…**保留修饰位点及两侧
相邻残基的原始坐标、编号、原子顺序和已记录的连接，作为链内模板的验证输入。
从封端分子开始参数化时，需要针对目标构型拟合或验证部分电荷，检查两端接入真实肽链时
涉及的键、键角、proper／improper 二面角和 1–4 相互作用。用短肽和完整蛋白分别通过
`gmx grompp` 和短能量最小化后，再核对构型与两侧肽键。
[GROMACS 新增残基说明](https://manual.gromacs.org/documentation/2025.4/how-to/topology.html)

### 在 GPU 机器启动

将 ZIP 解压到装有 GROMACS 2021 或更新版本的 GPU 运行环境，然后在包内执行

```bash
bash run_md.sh
```

脚本先在 CPU 上进行能量最小化，再为 NVT、NPT 和生产阶段启用 GPU 非键相互作用计算。
`GMX_BIN` 可指定 GROMACS 可执行文件，`bash run_md.sh --cpu` 可显式选择 CPU 模式。
脚本逐段运行 `grompp`，保留展开后的拓扑、日志与 checkpoint。若有有效 checkpoint，在同一
目录重运行上述命令可续跑。正式分析前应检查能量最小化、平衡和日志中的约束信息。
`manifest.json` 记录模拟设置和力场文件校验值，`index.ndx` 的 Protein 组包含已注册的
修饰残基，并为每条链提供 `Chain_<标识>` 索引组。`residue-map.json` 保留原始残基编号。

## 蛋白质翻译后修饰（PTM）

从 **插件 → 蛋白质翻译后修饰（PTM）…** 选择分子对象和坐标状态。按链或残基编号筛选，
用 Shift 或 Command／Ctrl 多选。Ser、Thr 和 Tyr 使用各自的磷酸化模板，Lys 可以
逐位点选择 L-乳酸化（2S）或 D-乳酸化（2R）。**预览侧链**显示临时棍状副本，
**应用为新对象**生成可独立着色、比较和导出的单状态对象。

**仅已有修饰**列出导入结构中的 `SEP`、`TPO`、`PTR`、`XRW` 和 `D8R`。
选中一个或多个已有修饰位点后，点击 **恢复原氨基酸**。新对象会将磷酸化残基恢复为
`SER`、`THR`、`TYR`，将两种乳酸化残基恢复为 `LYS`，并保留原残基重原子的
坐标和肽键。可通过同一窗口导出恢复后的 PDB。后续拓扑准备时可补齐侧链氢。

**选中位点**创建源对象中的 PyMOL 选择。预览和应用使用 wwPDB 化学组件字典
（CCD）校正副本里的残基内部重原子键。缺原子时会提示，已有坐标沿用导入值。
建模依赖完整侧链和单一构象，未优化的近接触会显示在状态栏。

**导出 PDB**写入显式 `CONECT` 和 MD 参数状态。模型使用 CCD 的重原子几何，
新增基团使用隐式氢，磷酸基采用 −2 的形式电荷。输出属于结构可视化模型，MD
拓扑和力场参数需在目标体系中另行准备。CHARMM-GUI 的 PDB Reader 给出了
SEP 补丁的官方实例。Huang 等人提供的 ERK K231 乳酸化补充文件用于
GROMACS 2021.4 和 AMBER ff14SB 配置。用于其他体系前需要核对目标力场、
残基命名、构型、原子顺序及与多肽的连接参数。
[CHARMM-GUI 示例](https://charmm-gui.org/?doc=demo&id=pdb_reader&lesson=1) ·
[乳酸化参数来源](https://doi.org/10.1038/s41589-025-02107-8)

PyTMs 用原生 PyMOL 编辑命令实现了磷酸化，其 GUI 依赖 Tk/Pmw。本功能通过
原生 ChemPy 模型接口载入键和坐标，模板来自 wwPDB CCD。
[PyTMs 论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4256751/) ·
[PyTMs 源码](https://github.com/Pymol-Scripts/Pymol-script-repo/blob/master/plugins/pytms.py) ·
[L-乳酸化 XRW](https://www.rcsb.org/ligand/XRW) ·
[D-乳酸化 D8R](https://files.rcsb.org/ligands/download/D8R.cif)

## 选择与表示（V）

点击对象列表右侧的 **V**，或命令栏旁的 **V 选择/显示**，打开中文表示窗口。
每一行可设置选择表达式、显示方式和颜色。

- 点 **all** 行的 **V** 可统一调整多个构象。用 **resname 快选** 选一个组分，例如
  `DPPC`，选好显示方式后点 **应用到全部分子**。启用的规则会更新各原对象中匹配的
  原子或珠，也会更新当前隐藏的构象。各对象的显隐状态保留。
- 点单个对象的 **V → 按组分分层** 后，可为每行选择显示方式和颜色，再点
  **原位应用显示与颜色**。例如让脂质保持棍状、粗粒化核酸用卡通，并分别着色。
  如果该对象正在使用 V 窗口生成的分层副本，应用成功后会回到原对象显示。
- **仅应用颜色**沿用现有显示方式和显隐状态。原位规则重叠时，后应用的颜色覆盖前面的颜色。
- 单对象的 **应用为分层副本** 可独立显示各行。**恢复源对象**会清理这些副本，
  恢复源对象的显隐。若已有副本在显示，可用此按钮回到原对象查看更新。

**resname 快选**自动列出当前对象实际存在的残基名称和原子/珠数量，名称去重，
支持搜索与滚动。点击名称会填入当前表示并更新匹配数量；切换对象或点击刷新会重新读取列表。
表达式仍可手动修改。启用 **自动应用** 后，修改选项或在表达式框按回车会原位应用显示与颜色。

独立副本的 **棍状（sticks）**只画选区内部的键，**球棍（ball-and-stick）**同时画
小原子球和键。原位显示沿用 PyMOL 在源对象上的键显示。预览会分别显示匹配原子数、
源内部键数和跨选择边界的键数。棍状和球棍要求有内部连接；
如果匹配到了原子却没有内部键，应用会说明原因并保留前次显示，不扩大选择或自动猜测化学键。
这时可选择球体，或提供含连接信息的 MOL2/SDF/已确认拓扑。原位应用保留源连接，
独立副本可复用已保存的完整 CG 模板。混合体系副本会保留模板范围外的源连接与键级。
粗粒化核酸的原位卡通沿已有骨架键绘制，保留链间与缺键处的断点。

窗口支持 [VMD 常用选择语法](https://www.ks.uiuc.edu/Research/vmd/current/ug/node89.html)的子集，例如：

- `resname AL31`：选择 ALC-0315 对应残基。
- `resname DPPC CHOL`：选择两类脂质。
- `nucleic`：选择核酸，兼容 Martini 粗粒化珠。
- `name BB*`：选择名称以 BB 开头的珠。
- `resid 1 to 10`：选择残基编号范围。
- `not water and (lipid or nucleic)`：组合选择条件。
- `within 5 of (nucleic)`：选择核酸 5 Å 内的原子或珠。

`index` 从所选分子的第 0 个原子开始，`serial` 对应文件中的原子序号；不支持的
VMD/Tcl 或数学语法会提示错误。表达式只用于选择，不作为命令执行。

对象列表原来的 **C** 按钮改为颜色小色块。点击可选择预设色，或通过 **更多颜色…**
选取任意颜色；多色对象的小色块显示第一个原子的代表色。表示窗口的色块可给各行独立配色。

对象列表的绘制、点击、拖动与释放共用 framebuffer 像素布局；点击前会更新被着色等操作
失效的列表缓存。原生回归脚本 `tools/validate_object_panel_hits.py` 在独立 PymolX 进程中
检查首/中/末行、普通/Motion 模式、滚动与缩放后的中心/四边/四角；
`PYMOLX_INVALIDATE_BEFORE_CLICK=1` 可验证着色后未重绘时的点击，结果目录由
`PYMOLX_TEST_ARTIFACTS` 指定。
